# Juan Ignacio Cacchione - Portfolio

Static, single-page portfolio (`index.html` + `site.css`) with no build step, image files, or JavaScript. All visuals are HTML/CSS concept views. Internal work is described at a high level; no Deere source code, reports, dealer names, financial figures, credentials, or production data is included.

## Preview locally

Open `index.html` in a browser. A web server is not required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository. A personal site repository is usually named `<your-github-username>.github.io`.
2. Upload the contents of this folder to the repository root: `index.html`, `site.css`, `.nojekyll`, and this README.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for deployment. The site will be available at `https://<your-github-username>.github.io/`.

Before making the repository public, review every file and image for employer-confidential details. Do not add internal scripts, real report screenshots, dealer/customer data, tenant URLs, access tokens, or credentials. Keep the internal MCP project as a sanitized case study unless company policy explicitly permits sharing more.
