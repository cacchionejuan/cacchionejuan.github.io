Featured project / Global data product

P2M: from one region to a global proposal.

Dealers couldn't see which parts fit the machines working around them. I created P2M, a Power BI product that connects machine population, parts catalogues and dealer inventory to answer exactly that.

  • Built for Latin America, already adapted in Australia.
  • Presented live to the global team as a candidate for one worldwide model.
  • Proof of concept for scale: 4 regions and a 30M+ row bridge in Databricks.
  • Model standardized in days, not weeks, with AI-assisted development.
  • Power BI · PBIP / TMDL
  • Databricks SQL
  • Data modeling
  • Stakeholder demos
